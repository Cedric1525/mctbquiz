MODIFIER LES QUESTIONS
----------------------
Tout se passe dans MCTB_Banque_Questions.xlsx.

1. Ajoutez ou modifiez les lignes de l'onglet Questions.
2. Pour un nouveau questionnaire, declarez-le d'abord dans l'onglet
   Questionnaires : il apparaitra alors dans la liste deroulante.
3. Regenerez questionnaires.json.
4. Remplacez le fichier sur GitHub et incrementez le cache dans sw.js.

Un meme enonce avec une image differente compte comme une question
distincte : c'est ce qui permet les series de reperage sur schema.

Colonne "Questions a tirer" :
   0  = toutes les questions, dans un ordre melange
   15 = 15 questions tirees au hasard a chaque passage

Colonne "Actif" : "non" retire un questionnaire de l'affichage sans le
supprimer du classeur.


POINTS DE VIGILANCE POUR LA REDACTION
-------------------------------------
- Sur un Vrai/Faux, l'enonce ne doit pas etre absolu si l'explication
  est conditionnelle ("lorsque", "si", "sauf"). Sinon, le candidat qui
  connait les exceptions est penalise.
- Sur une question a choix multiples, au moins une option doit etre
  fausse : sinon tout cocher donne toujours la bonne reponse.
- Les lettres de la colonne Reponses designent les lignes du tableau,
  pas ce que voit le technicien : l'application melange l'ordre des
  options a chaque passage, en suivant les textes.
